Progress saves to data/progress.json in your app folder and survives restarting the program or clearing browser storage. Keep that folder when updating. Download a JSON backup to move to another computer. Restore merges new applications and skills; existing application records and nonempty profile fields are preserved. This is a single-user local app, not cloud sync.

Skill coverage = your matching recognized keywords ÷ all recognized skill keywords in the job text. It uses a fixed dictionary, treats optional and required mentions equally, and can miss wording variations. It is not a qualification score or hiring probability. Eligibility answers and preparation tasks are self-reported.
